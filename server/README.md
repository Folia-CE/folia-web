# 纯静态网页版 · 部署说明

这个文件说明 `server/static-server.mjs` 存在的**唯一理由**，以及它**明确不做什么**。

## 它在做什么

网页本体是纯静态的（`vite build` 出来的 `dist/`）。但网易云 / QQ 音乐 / 酷狗的接口
**都不返回 `Access-Control-Allow-Origin`**，浏览器里直接 `fetch` 一定会被 CORS 拦掉 ——
这是浏览器的硬限制，改前端代码解决不了。

所以这个服务做两件事：

1. **把 `dist/` 当静态站点发出去**（网页还是纯静态，没有服务端渲染）。
2. **在同一个来源下跑内置的接口代码**（`src/webBridge/api/*.js`，来自 folia-sonnet 的
   `nativeBridge`，本来就是纯 JavaScript）。页面与它同源，请求不触发 CORS。

登录态（cookie）只存在于**进程内存**里，不落盘。进程一退就要重新扫码。

## 它明确不做的事（重要）

### 不搬运音频

**歌曲永远由浏览器直接从各家 CDN 拉**，不经过这个服务。

服务端只负责「去要一个播放地址」这个 JSON 动作：

```text
GET /api/__folia_bridge  {"provider":"netease","operation":"/song/url/v1",...}
  → {"code":200,"data":[{"url":"http://m802.music.126.net/....mp3", ...}]}
```

拿到地址之后，是浏览器的 `<audio>` 元素直接去 `m802.music.126.net` 取字节。这个服务
在整条播放链路里只出现一次，转的是几百字节的 JSON，不是几十兆的音频。

原因很实际：**一台机器扛不住**。一首无损几十兆，几个人同时在线就能把带宽和内存吃满，
而这个进程是单机、单线程的。搬运音频不是「性能优化问题」，是这个架构根本不该做的事。

代码里为此有两道闸：

- 响应层面：凡是 `audio/*`、`video/*`、`application/octet-stream` 的答复一律
  `415` 掐断（`FORBIDDEN_RESPONSE_PREFIXES`）；
- `allowScripts`/上游白名单只列接口主机，不列媒体 CDN 的下载路径。

### 不存任何账号

不写数据库、不落盘、不连任何第三方服务器。cookie 在进程内存里，退出即失效。

## 跑起来

```bash
npm ci
npx vite build          # 产出 dist/
node server/static-server.mjs
# 打开 http://127.0.0.1:4173
```

可选环境变量：

| 变量 | 默认 | 说明 |
|---|---|---|
| `HOST` | `127.0.0.1` | 只听本机；要让局域网访问才改成 `0.0.0.0` |
| `PORT` | `4173` | 端口 |

### 只想托管静态文件？

也可以。把 `dist/` 丢给任意静态托管（Nginx、GitHub Pages、Vercel 静态）。
这种情况下 `isWebBridgeAvailable()` 探测会失败，应用自动退回「需要自己配
`VITE_*_API_BASE`」的旧行为 —— 本地登录不可用，但其余功能照常。

## AI 云缓存

网页版还有一个独立于上面这台服务的功能：**AI 主题的云缓存**（设置 → 外观 → 云缓存）。

- 按歌词文件的 MD5 存/取 AI 生成的主题。别人生成过的歌词你直接取答案，**不需要自己的 AI Key**；
  自己生成完也会回传，帮下一个人省一次。
- 缓存服务地址可换（自建同一套接口即可），开关默认打开，随时可以关掉。
- 它**不经过**上面那台静态服务：页面直接去 `https://apif.tangbot.xyz`（或你填的地址）。
  关掉它不影响任何已有功能，只是每次都要自己生成主题。

## 各家平台的能力对照

| 平台 | 未登录 | 登录后 | 说明 |
|---|---|---|---|
| 网易云 | 搜索、歌单、歌词、播放地址 | + 我的歌单、红心、云盘 | 扫码登录 |
| 酷狗 | 搜索、歌单、歌词、播放地址 | + 我的歌单、收藏 | 扫码登录 |
| QQ 音乐 | 搜索、新歌、排行榜、歌单 | + 我的歌单、红心 | 扫码登录（QQ / 微信两条通道） |
| 汽水音乐 | — | — | 需要 Windows 原生签名模块，网页版不支持 |

## 隐私

- 凭据只在本机内存里，服务不落盘、不上报。
- 请求直接发往各家官方接口，不经过任何中转服务器。
- 这个服务只监听 `127.0.0.1`（除非你显式改 `HOST`），局域网外访问不到。
